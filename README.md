# AimForge

AimForge is a local-first Valorant aim routine and consistency tracker for serious players who want a short, repeatable block instead of an endless aim-trainer menu.

## What is included

- A 20-minute Ascendant+ routine built around first-bullet quality, movement timing, target transfer, and pressure.
- Locked progression: the next drill is unavailable until the current timer reaches zero.
- Pause/resume support without a skip button.
- Automatic pause when the browser tab is hidden or reloaded.
- Session history stored in the browser's local storage.
- Current streak, best streak, monthly target, total focus time, weekly rhythm, 12-month heatmap, and recent session log.
- Responsive desktop and mobile layout.

## Run it

This is a dependency-free static project. Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.

## Training philosophy

The routine is intentionally short. It is designed to make focused reps easy to repeat, not to claim that one drill is universally best for every player. Keep the block stable for at least two weeks, watch consistency and ranked performance, then adjust one drill at a time.
